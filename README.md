# MIDI Keyboard

An open source, custom built MIDI keyboard designed from scratch. This project aims to create a functional and programmable musical instrument through custom PCB development, embedded firmware and hardware-software integration. 

The keyboard will allow users to send MIDI signals to computers and compatible music production software, providing a physical interface for playing instruments and creating music. 

# Features
- Physical keypad inputs
- programmable keyboard inputs
- MIDDI signal generation
- USB connectivity
- firmware for processing keyboard inputs
- compatibility with MIDI enabled software and virtual instruments.

# Hardware
The project will involve designing a custom electronic circuit and PCB to handle keyboard input detection and MIDI communication. 

**Main hardware components**:
- microcontroller
- keyboard switches
- input detection circuitry
- usb connector
- supporting electronic components

# Firmware
The firmware will handle: 
- Reading keyboard inputs.
- Detecting key presses and releases.
- translating keyboard inputs into MIDI messages.
- sending MIDI data to connected devices.
- managing simultaneous key presses.
